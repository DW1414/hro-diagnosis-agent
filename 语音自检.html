结果解读：
· API 不支持 → 这个浏览器没有语音识别能力（常见于内置浏览器 / 部分国产浏览器壳），换 Chrome 或 Edge 打开即可；
· network → API 有、但云识别服务器连不上（Chrome 走 Google、Edge 走微软，国内网络常见），需代理或改用云端识别方案；
· not-allowed / audio-capture → 麦克风权限被拒：浏览器地址栏左侧图标里放开，并检查 Windows 设置 → 隐私 → 麦克风；
· service-not-allowed → 页面来源不受信任（需 https 或 localhost）。
